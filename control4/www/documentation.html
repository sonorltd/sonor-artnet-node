Sonor Art-Net DMX Node

Drives any Art-Net node (SONOR Art-Net Node, Enttec ODE, …) straight from the controller over UDP 6454. Sixteen Fixture light proxies each map to a DMX start address and fixture type, and every RGB / RGBW fixture gets the OS 3.3 colour wheel and CCT slider in Navigator, works in Lighting Scenes, and reports its level back to keypad LEDs.

Setup

  1. Set Node IP (the node's own config page shows it; 2.0.0.10 out of the box with no DHCP). Match Art-Net Net / Sub-Net / Universe to the node — the defaults (0 / 0 / 0) are the node's factory settings.
  2. For each fixture: set Slot n Address (DMX start channel, 1–512; 0 = unused) and Slot n Type:
    • Dimmer — 1 channel [L]
    • RGB — 3 channels [R G B]; CCT picks are rendered as a blackbody RGB mix
    • RGBW — 4 channels [R G B W]; CCT picks drive the W LED and tint it with RGB away from White LED Kelvin (set this to your strip's white LED temperature); colour picks move the common part of RGB onto W when RGBW White Extraction is On
    Rename the fixtures in Composer and hide unused ones. Check Node Status — it shows the node's name and IP once it answers ArtPoll.
  3. Fixtures that share a start address are driven in unison; overlapping ranges are your responsibility.

Properties

Refresh Interval (s) — a full frame is re-sent this often when nothing is fading (0 = only on change). The SONOR node holds the last look if frames stop; leave at 2 s so a rebooted node picks the look back up. Default Fade (ms) — used when Navigator / programming gives no rate. Default On Level — used by ON when the fixture has no remembered level.

Programming

Commands: Set Fixture Level (fixture 0 = all), Set Fixture Colour (RGB 0–255, fixture 0 = all), Set Channel (raw DMX channel 1–512, bypasses the slots), Blackout On/Off, Identify Fixture (flashes it white three times).
Actions: Reconnect, Poll Node, Resend DMX Frame, All Fixtures Off.
Events: Node Found, Node Lost (no ArtPollReply for 10 s), Blackout On, Blackout Off.

Notes

DMX fixtures don't fade themselves — the driver runs a 25 Hz software fade and sends a full 512-channel frame while anything is moving. One driver instance per node / universe; add it again for a second node. Turn Debug On to see packets and proxy traffic in the Lua output.

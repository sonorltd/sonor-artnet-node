In QLC+ (free, Mac/Win): Inputs/Outputs → Universe 1 → tick the Art-Net output on your laptop's interface → set the target to the node's IP (or leave broadcast). Add a dimmer fixture, push the fader. The node's status page counts frames received — if that's climbing, packets are arriving and any problem is on the DMX side (A/B swapped is the usual one). If it isn't climbing, it's universe or subnet: the node and the console must be on the same subnet, and Port-Address 0/0/0 is "Universe 1" in QLC+'s and Universe 0 in MA.

Any Art-Net tool's node discovery (QLC+ Art-Net plugin config, Enttec DMX-Workshop, Resolume, MA) should list it as SONOR Node with one output port.

Control4 · DriverWorks

Control4 driver

Drive the node from Control4 with the OS 3 colour wheel — no eDIDIO or other DMX gateway in between. The controller speaks Art-Net to the node itself; sixteen fixtures show up in Navigator as dimmers with colour and CCT, work in Lighting Scenes, and keep keypad LEDs honest.
sonor_artnet_dmx.c4z
Driver v0.1.0 · OS 3.3+ · one instance per node / universe
Download .c4zSource on GitHub

Why this works without a gateway

Control4's colour wheel and CCT slider live in the light_v2 proxy, not in any particular piece of hardware. Any DriverWorks driver whose light proxies advertise supports_color gets the wheel, so there is nothing to emulate — the driver builds ArtDmx packets in Lua and sends them from the controller to the node over UDP 6454. The eDIDIO route only ever looked mandatory because that was the driver most dealers had seen it on.

1 Install

Composer Pro → Driver → Add or Update Driver or Agent → pick the .c4z. Then System Design → Add Driver, search Sonor Art-Net, drop it in the room. Set Node IP to the node's address (its own web page shows it; 2.0.0.10 with no DHCP) and match Art-Net Net / Sub-Net / Universe to the node — the defaults 0 / 0 / 0 are the node's factory settings. Node Status flips to the node's name once it answers ArtPoll.

Set Slot n Address to the fixture's DMX start channel (0 = unused) and its Type; rename the fixture in Composer and hide the unused ones. Sixteen slots per driver — add the driver again for a second node or universe.

3 Programming

Commands: Set Fixture Level and Set Fixture Colour (fixture 0 = all), Set Channel (raw DMX 1–512, bypasses the slots), Blackout On / Off, Identify Fixture (three white flashes). Actions: Reconnect, Poll Node, Resend DMX Frame, All Fixtures Off. Events: Node Found, Node Lost, Blackout On, Blackout Off.

How it behaves on the wire

DMX fixtures don't fade themselves, so the driver runs a 25 Hz software fade and sends a full 512-channel frame while anything is moving. When nothing is moving it re-sends the frame every Refresh Interval (2 s default) so a node that has been power-cycled picks the look back up — the node itself holds the last look if frames stop. Frames go unicast to Node IP, so it works across VLANs as long as UDP 6454 is routed.

Works with any Art-Net node, not only this one — an Enttec ODE takes the same packets. The driver has been checked offline against an Art-Net packet / colour-maths harness (control4/test/harness.lua); turn Debug on for the first install and watch the Lua output. Sister driver: the Pixel Conductor driver uses the same light_v2 colour approach for WLED strips.

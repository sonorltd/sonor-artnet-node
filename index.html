Art-Net Node

Ethernet → DMX512 on an Arduino Nano + ENC28J60 shield. A drop-in stand-in for an Enttec ODE when the old software won't play. Firmware v0.2.0.
Download .hex Sketch + libraries (zip) GitHub repo
DiscoverableAnswers ArtPoll as “SONOR Node” — shows up in QLC+, DMX-Workshop, Resolume, MA, Control4 Art-Net drivers.
One universe outArtDmx → 512 channels of continuous DMX on the Nano's TX pin via a MAX485. Holds last look on loss of source.
Config page on the nodeBrowse to its IP to set Net / Sub-Net / Universe, DHCP or static IP. Wiring + flashing notes are on the page too.
Zero library installsEthernetENC (patched) and DMXSerial are bundled inside the sketch. Open the .ino, pick the board, Upload.

Wiring

Arduino Nano             MAX485 module              XLR (DMX out, female)
────────────             ─────────────              ─────────────────────
5V   ───────────────►  VCC
GND  ───────────────►  GND  ──────────────────────► pin 1  (shield / GND)
D1 (TX) ────────────►  DI
D2   ───────────────►  DE  ┐ (tie DE and RE together)
                       RE  ┘
                       A   ──────────────────────► pin 3  (Data +)
                       B   ──────────────────────► pin 2  (Data −)
                       RO  (leave unconnected)
D3   ──► 330Ω ──► LED ──► GND        (optional activity LED)
The shield owns D10–D13 (SPI). The on-board D13 LED flickers with SPI traffic — normal. If you'd rather not use D2, tie DE+RE to 5 V and set DMX_DE_PIN -1.

Flashing

Arduino IDE: open sonor-artnet-node.ino → Board Arduino Nano → Processor ATmega328P (Old Bootloader) for clones (plain ATmega328P for a recent genuine one) → Port → Upload. Nothing to install: the libraries are in src/. Don't also install EthernetENC from Library Manager — the stock copy won't link with DMXSerial.

No IDE, just the hex:

# old-bootloader clone (most Nanos)
avrdude -c arduino -p atmega328p -P /dev/cu.usbserial-XXXX -b 57600  -D -U flash:w:sonor-artnet-node.ino.hex:i
# new bootloader (genuine Nano since 2018)
avrdude -c arduino -p atmega328p -P /dev/cu.usbserial-XXXX -b 115200 -D -U flash:w:sonor-artnet-node.ino.hex:i

Config page

Plug in Ethernet, wait ~6 s, browse to the node's IP. On a network with DHCP it takes a lease (find it in the router's lease table under MAC 02:53:4F:4E:4F:52, or via any Art-Net tool's node discovery). With no DHCP it sits on 2.0.0.10 / 255.0.0.0 like an ODE out of the box — set your laptop to 2.0.0.1 / 255.0.0.0.

SectionWhat it does
Art-NetNet 0–127, Sub-Net 0–15, Universe 0–15. Applies immediately on Save. Port-Address 0/0/0 is “Universe 1” in most consoles, Universe 0 in QLC+ and MA.
NetworkDHCP (with static fallback) or Static; IP / mask / gateway. Applies after a power-cycle.
StatusCurrent IP, MAC, port address, DMX state.
Factory resetSet Net 127 / Sub-Net 15 / Universe 15 and Save — or just re-flash.

Quick test on site

D3 LED on during boot, off once the network is up, then toggles on every Art-Net frame received for the configured universe. Not toggling → packets aren't reaching it (universe or subnet). Toggling but nothing lights → DMX wiring or polarity (swap A/B).

Limits

Single universe — a 328P has 2 KB of RAM. Flash ≈ 28.7 KB / 30 KB, RAM ≈ 1.4 KB / 2 KB. Refresh follows the source; the DMX line runs continuously at ~44 Hz regardless.
